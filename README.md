# Бим Моторс

Production-ready проект сайта автосервиса и шиномонтажа «Бим Моторс» в Мытищах.

## Структура

```text
frontend/  Next.js + React + TypeScript + Tailwind CSS
backend/   PHP 8.2 endpoint для заявок
```

## Быстрый старт

```bash
cd frontend
npm install
npm run dev
```

Для форм:

```bash
cd backend
cp config.example.php config.php
php -S 127.0.0.1:8080
```

Подробности лежат в `frontend/README.md` и `backend/README.md`.
